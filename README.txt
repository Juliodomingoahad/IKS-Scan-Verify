IKS Scan & Verify V7

Android-first scanner/analyzer.

1. Upload index.html, manifest.webmanifest and README.txt to the GitHub Pages repository.
2. Open: https://juliodomingoahad.github.io/IKS-Scan-Verify/
3. Use the Android camera input to capture the marking.
4. Run Analyzer, inspect the 7x58 matrix, then Decode.
5. Tes Decoder Internal must show SELF-TEST PASS before testing a photo.

Catatan: V7 does not reproduce proprietary authentication/traceability systems. The 58x7 mode is a reference-style diagnostic profile based on the supplied IKS reference artwork. Standard DotCode decoding is attempted through Sythos when available.
